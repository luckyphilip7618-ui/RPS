# Rock Paper Scissors

A responsive Rock Paper Scissors game built with plain HTML, CSS and JavaScript.

## Run it

Open `index.html` in a browser.

No server or installation is required.

## Included

- Responsive mobile-friendly interface
- Player vs Computer
- Animated computer thinking
- Score tracking
- Wins, losses and ties
- Best-of-5 game
- Reset game
- Play Again modal
- No external libraries

## Next development steps
